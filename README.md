# Kapil Dhimal – 3D Portfolio (Next.js + React)

## Run it
```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```
Deploy: push to GitHub and import the repo in Vercel.

## Edit your content
- `lib/data.js` – projects, language percentages, focus chart, logos/colours.
- `components/AboutContact.jsx` – about text and email.
- `components/Scene3D.jsx` – colours and shapes of the 3D hero.
